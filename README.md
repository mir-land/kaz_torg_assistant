# 🛒 SmartRetail Kiosk — ИИ Ассистент для магазина

**Голосовой ИИ-помощник** для торговых точек с поддержкой казахского и русского языков.

> **Статус:** Бета-версия. Доступна для тестирования.

---

## 🎯 Что умеет

- 🎙️ **Слышит клиента** — распознаёт речь на казахском и русском
- 🧠 **Отвечает умно** — генерирует ответы через LLM (Qwen/GPT)
- 🔊 **Говорит вслух** — синтез речи (Azure TTS)
- 🔄 **AEC** — подавление эха, можно перебить агента во время речи
- 👥 **Режим продавца** — продавец может подключиться к диалогу
- 📱 **Два режима UI** — Touch (сенсорный киоск) и Glass (прозрачный)

---

## 🚀 Быстрый старт (готовый .exe)

1. Скачать последний релиз → **[Releases](../../releases)**
2. Распаковать в любую папку
3. Запустить `SmartRetailKiosk.exe`
4. Открыть ⚙️ Настройки → выбрать микрофон → Сохранить

> **Требования:** Windows 10/11, микрофон, интернет

для тестирования 7 дней на демонстрацию
